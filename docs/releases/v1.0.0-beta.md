# Atlas AI v1.0.0-beta

Atlas AI is an open-source AI Financial Intelligence Platform that keeps deterministic finance calculations separate from optional AI explanation.

## Highlights

- Turkish-first financial workspace with dashboard, monthly plan, forecast, decision simulation, Financial Memory, reminders, and AI Coach.
- Deterministic cash-flow, living-budget, risk, debt-priority, and payoff calculations.
- Provider-independent AI adapters with structured validation and Mock fallback.
- Database-free public demo using fictional, per-tab, non-persistent data.
- PostgreSQL self-host mode through Prisma with guarded integration-test infrastructure.
- English public website, architecture documentation, open-source policies, and release-quality automated tests.

## Public Demo

The `/demo` workspace requires no database or paid AI key. It uses an immutable fictional seed, keeps changes in active-tab memory, resets on refresh, and calls Mock AI only. Do not enter real financial information.

The production demo URL will be added after a verified deployment.

## Self-hosting

Self-host operators supply their own PostgreSQL database and optional server-side AI provider credentials. Mock mode works without an AI key. Authentication and user ownership are not included, so database mode must not be exposed as a public multi-user financial service.

## AI Provider Support

- Mock: default and fully available without credentials.
- Gemini: server-side adapter; browser mode experimental and production-disabled.
- OpenAI and Anthropic: self-host only.
- OpenRouter: server-side adapter; browser mode experimental and production-disabled.
- Ollama and LM Studio: local/self-host; browser connectivity depends on local CORS configuration.
- Custom OpenAI-compatible: self-host only for remote endpoints.

AI explains minimized deterministic results. It does not calculate budgets, risk, payoff order, or financial truth.

## Security and Privacy

- Public demo has no database credentials, owner-owned AI keys, analytics, or persistent financial state.
- Self-host credentials remain server-side environment variables.
- Demo API/database boundaries fail closed and secret scanning is part of CI.
- Vulnerabilities should be reported through the private process in [SECURITY.md](../../SECURITY.md).

## Testing

The release gate covers secret scanning, dependency audit, lint, unit tests, isolated PostgreSQL integration tests, normal and demo builds, standard and demo Playwright suites, responsive behavior, reduced motion, public metadata, internal links, and storage-negative demo controls.

## Known Limitations

- The release audit records four moderate transitive dependency advisories across the bundled PostCSS and `gaxios`/UUID paths. No high or critical advisory is reported by the configured production audit gate, and the breaking forced downgrade is intentionally not applied.
- No authentication, user ownership, or multi-user authorization.
- No banking import, account aggregation, payment execution, email, SMS, or push delivery.
- Public demo data is fictional and non-persistent; Mock AI output is illustrative.
- Browser cloud BYOK is experimental and disabled in production.
- Forecasts and scenarios are assumption-bound educational projections, not guarantees.
- Atlas AI provides educational decision support, not regulated financial advice.
